## v0.36.0 — KB-only memory, slaude-cron-only, subtle task markers

This release hardens two runtime behavioral guarantees that were previously advisory: memory writes now go exclusively through `kb_memoize` (the harness `# auto memory` instructions are explicitly overridden at the soul layer), and SDK cron tools are denied at the project settings level so only `mcp__slaude_runtime__*` cron tools are reachable. A minor UX fix rounds it out: task list markers drop the heavy emoji in favor of text-weight characters.

### Features

- **Runtime: KB-only memory writes (soul override).** `RUNTIME_BASELINE` in `soul/loader.ts` now includes a `## Harness overrides` section that explicitly supersedes the SDK-injected `# auto memory` instructions. Agents must use `kb_memoize` as the sole write path for persistent memory — `memory/*.md` files and `MEMORY.md` updates are blocked. The override is injected at the soul layer so it arrives before any per-turn harness injection and can't be silently ignored.

- **Runtime: slaude-cron-only via `.claude/settings.json`.** `CronCreate`, `CronDelete`, and `CronList` SDK tools are denied at the project level. Only `mcp__slaude_runtime__*` cron tools (which carry proper Slack channel context) are reachable. `.gitignore` updated to allow `.claude/settings.json` to be committed, so this policy travels with the repo.

### Fixes

- **Tasks: subtler task list markers.** Replaced `✅`/`▶` with `✔`/`→`/`○` across both `formatTaskList` (TaskCreate/TaskUpdate) and `formatTodoList` (TodoWrite) in `gateway.ts`. The previous emoji markers were visually heavy and inconsistent with the surrounding Slack text weight.

### Internal

- `CLAUDE.md`: working rules aligned to KB-only memory write convention.
