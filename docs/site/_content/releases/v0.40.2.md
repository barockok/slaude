## v0.40.2 — `/compact` auto-boot on idle session

### Fix

- **`/compact` on idle session auto-boots instead of erroring.** Previously, calling `/compact` when no session was live returned a `:warning: no active session` warning. The correct behaviour is to boot the session and compact immediately — which is exactly what the user intended. The handler now sets up the route (or updates the existing one) with `wasCompacting = true` and calls `sendMessage` with `/compact` to start the session and trigger compaction. The existing `compacting` → `done` event flow posts the `:white_check_mark: compacted` confirmation as normal.
