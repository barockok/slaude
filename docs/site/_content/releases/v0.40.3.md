## v0.40.3 — `/compact` uses emoji reactions instead of text replies

### Fix

- **`/compact` feedback via reactions, not text.** The hourglass text reply (`:hourglass_flowing_sand: compacting context…`) and the done text reply (`:white_check_mark: compacted`) are replaced with emoji reactions on the original `/compact` message: ⚙️ (`gear`) while compacting, ✅ (`white_check_mark`) when done. The ✅ is already applied by the standard `done` event handler for all sessions — no duplicate; the text reply is simply removed.
